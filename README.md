# The Five Star Legacy 🇧🇷

**One Nation. Five Stars. A Legendary Story.**

Website edukasi interaktif tentang perjalanan Timnas Brasil di FIFA Men's World Cup hingga edisi 2022.

## Jalankan secara lokal
Tidak memerlukan build step atau dependency:
1. Download atau clone repository.
2. Buka index.html di browser, atau jalankan local server sederhana.
3. Pastikan koneksi internet aktif untuk Google Fonts dan foto Wikimedia Commons.

## Deploy dengan GitHub Pages
1. Buka Settings → Pages di repository.
2. Pada Build and deployment, pilih Deploy from a branch.
3. Pilih branch main dan folder /(root), lalu Save.
4. Tunggu GitHub Pages menerbitkan situs.

## Fitur
- Timeline horizontal yang dapat digeser/drag, difilter, dan dipilih; pada HP berubah menjadi timeline vertikal.
- Direktori pemain dengan pencarian, filter posisi, dan modal profil.
- Interactive Football Pitch untuk starting XI final 1970, 1994, dan 2002.
- Player Comparison dengan statistik Piala Dunia.
- Match Story Mode untuk final 1970, 1994, dan 2002.
- Animated Statistics, generasi emas, Did You Know, shareable fact card, dan kuis 10 soal dengan personal best di LocalStorage.
- Mobile-first layout, reduced-motion support, metadata SEO, dan sumber materi.

## Catatan data
- Timeline mencakup edisi yang diikuti Brasil dari 1930 sampai 2022.
- Brasil memiliki lima gelar: 1958, 1962, 1970, 1994, dan 2002.
- Brasil memainkan enam final resmi sampai 2002 (termasuk final 1998). Tahun 1950 merupakan runner-up pada final round-robin, bukan pertandingan final tunggal.
- Line-up pada lapangan merepresentasikan starting XI final pada masing-masing turnamen. Posisi pemain adalah ilustrasi untuk membantu pemahaman, bukan data pelacakan posisi.
- Statistik pemain berfokus pada Piala Dunia putra, bukan seluruh karier tim nasional.
- Beberapa foto diambil dari Wikimedia Commons. Periksa halaman file untuk keterangan lisensi dan atribusi sebelum penggunaan ulang.
